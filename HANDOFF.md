## 1. Objective

Build **Kalinga Sthapatya (କଳିଙ୍ଗ ସ୍ଥାପତ୍ୟ)** — a static educational website about Odisha's temple
architecture for families and kids, hosted on GitHub Pages
(repo https://github.com/sabyasachi-swain/kalinga-sthapatya → future URL
https://sabyasachi-swain.github.io/kalinga-sthapatya/).

Non-negotiables (full rules in `CLAUDE.md` and the `kalinga-content-policy` skill):
- **Every fact is cited** to an accepted academic / ASI / UNESCO source; unverifiable → left blank.
- Facts live only in `data/*.json`; pages are **pre-rendered** from them by `scripts/build.mjs`.
- **All visuals are generated by the human with Gemini**; Claude writes briefs and reviews, never draws.
- Evidence tiers 🟢 Established / 🟡 Scholarly view / 🔴 Debated on every claim.

## 2. How the build is run

- **Orchestration:** the main session is the orchestrator (skill `/kalinga-orchestrator <phase>`, which only
  the human can invoke — if unavailable, follow `.claude/skills/kalinga-orchestrator/phases.md` directly).
  Work is delegated to 6 project agents in `.claude/agents/`: `kalinga-researcher`, `kalinga-fact-checker`
  (both Opus), `kalinga-visual-brief-writer`, `kalinga-frontend-builder`, `kalinga-asset-integrator`,
  `kalinga-qa-auditor` (Sonnet). Workers cannot spawn agents; files are the handoff.
- **Guardrails that are live:** `.claude/hooks/enforce-ownership.mjs` (each agent may only write its lane;
  `data/` content, validator, merge script, `.claude/` are protected) and `.claude/hooks/validate-on-data-edit.mjs`
  (validator runs after any data edit). Validator: `scripts/validate-content.mjs`. Data enters `data/` ONLY via
  `node scripts/merge-staged.mjs research/staged/<topic>.json` (validates, merges, rolls back on failure).
- **Research pipeline:** researcher → `research/ledgers/<topic>.json` (verbatim quotes) → independent
  fact-checker → `research/verdicts/<topic>.json` + `research/staged/<topic>.json` → human gate G2 →
  merge script → `data/`.

## 4. Key findings so far (don't re-learn these)

- The research report (`Odisha Temple Archtecture research.md`) is **leads only** and has errors. Corrections
  are in `.claude/skills/kalinga-content-policy/pitfalls.md` (updated 2026-09-19), e.g. Lingaraja is credited by
  Panigrahi to **Yayati II + Uddyota Kesari** (not Yayati I); Mukteshvara is Brown "c. 975" (not 950);
  Parasuramesvara Brown "late 8th c." (c. 650 not found in any source); the Epigraphia Indica XIII cave-inscriptions
  article is by **R. D. Banerji**.
- **Heights conflict:** Konark surviving jagamohana ≈39 m (Mitra) vs 30 m (ASI web) → published as 🔴 with note.
  Lingaraja → **null** (128 ft / 160–165 ft / ~180 ft / >180 ft, no ASI figure).
- **Era framework:** no accessible source uses "Formative/Transitional/Mature"; Percy Brown 1959 uses
  Early c. 750–900 / Middle c. 900–1100 / Later c. 1100–1250. Staged eras keep the G0 labels but use Brown's
  dates — **human decides at G2**.
- Method that works: archive.org **search-inside** (item's `fulltext/inside.php` OCR search) counts as full-text
  evidence; locators are "scan leaf N (printed page unverified)".
