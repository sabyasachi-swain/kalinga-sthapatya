## 6. Key knowledge (don't re-learn)

- **Commands:** build `node scripts/build.mjs` · staleness `--check` · content `node scripts/validate-content.mjs`
  (`--strict` before launch, `--staged <file>` for fragments) · merge `node scripts/merge-staged.mjs <file>` ·
  links `node scripts/check-links.mjs` · layout `node scripts/qa-probe.mjs --port 8097 --pages a.html,b.html`.
- **qa-probe quirks:** it fails with EADDRINUSE if a previous run left the port bound — pass a fresh `--port`, or
  kill the listener first (`Get-NetTCPConnection -LocalPort <p> -State Listen | Stop-Process -Id $_.OwningProcess`).
  Categories A/B/F/G are blockers; D (text < 14px) and E (targets < 44px) still report known shared-component
  issues that task C12 is meant to fix.
- **Screenshots:** serve the repo root (`python -m http.server 8080 --bind 127.0.0.1`), then
  `"C:/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --hide-scrollbars --screenshot=… --window-size=1440,900 <url>`.
  **Do not take very tall screenshots of temple pages:** tour steps are sized in `vh`, so a 7000px-tall window
  stretches the page and hides content. Instead use a 1440×900 (or 375×812 iframe) wrapper that scrolls to an
  offset, e.g. `<iframe src="…" style="width:1440px;height:900px">` plus `contentWindow.scrollTo(0, y)`.
  DOM probes: `--dump-dom --virtual-time-budget=4000` with a script writing results into a `<pre>`.
- **Prompt files:** `CODING-PROMPTS.md` (Block C = the shared rules; C1–C9, all delivered) ·
  `CODING-PROMPTS-2.md` (C10–C18) · `research/RESEARCH-PROMPTS.md` (Block G + 17 research topics).
  Every task prompt is written as Objective · Facts you may rely on · Steps · Guardrails · Output format · Acceptance,
  and tells the model to state assumptions rather than invent facts.
- **Recurring bugs in outside-model code** (check for these first when reviewing): treating `ctx.data.elements` or
  `ctx.data.media` as arrays (they are `{ elements: [] }` / `{ assets: [] }`); passing a whole `<script>` tag into
  `page()`'s `scripts` array (it takes paths); inlining the same SVG more than once without namespacing its ids;
  emitting class names that no CSS file styles; `<p>` nested inside `<p>` from wrapping `claim()` output.
- **Design contract:** `qa/TEMPLE-JOURNEY-SPEC.md` (journey structure), `qa/UI-REVIEW-2026-09-19.md` (the audit that
  drove the redesign), and the `kalinga-design-system` skill.
- **Content pitfalls:** `.claude/skills/kalinga-content-policy/pitfalls.md`. Heights: Konark 39 m 🔴 · Lingaraja null ·
  Mukteshvara ~10.5 m 🟡 · Parasuramesvara ~13 m 🔴 · Jagannath 65.4 m 🔴.
- **Media wiring without a schema change:** assets in media.json carry `temple_id`, `role` (`build-sequence` with
